# Omni Desktop research

Status: current research index

## Current conclusions

- Agent Skills provide the most portable content shape.
- Agent Plugins provide an emerging portable package shape for skills and MCP.
- Claude Code, Codex, Cursor, and OpenCode still differ in manifests, catalogues, paths,
  identity, precedence, caches, and executable components.
- Cursor belongs in the portable skill lane and has both Agent Plugin and native Cursor
  Plugin formats.
- Provider caches and hooks must be observed and planned, not treated as ordinary files.
- Ports and adapters with a lightweight DDD vocabulary is the current architecture
  direction to validate with a vertical slice.
